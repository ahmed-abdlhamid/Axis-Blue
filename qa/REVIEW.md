# مراجعة AXIS Blue — تحديث المحتوى والواجهة

تم التنفيذ محليًا بتاريخ 2026-10-24 على الفرع الحالي `main` وفق الطلب المرفق. لم تُنفذ عمليات إنشاء فرع أو commit أو push أو merge أو deployment. كانت شجرة العمل نظيفة عند بداية الجولة.

استُخدمت مهارات Frontend Design وResponsive Design وWebapp Testing. لم تُثبت اعتماديات أو متصفحات أو مجموعة اختبارات جديدة؛ عُدلت الفحوص الموجودة واستُخدم Chrome المثبت مع Playwright وSharp المتاحين في البيئة.

## ما تغير

- ترتيب الرئيسية: الهيرو، الخدمات، المنتجات، من نحن، التواصل. بقيت روابط الهيدر للصفحات المستقلة، مع خط سفلي فقط للصفحة الحالية والهوفر دون تفعيل حسب التمرير.
- هيرو بعرض الصفحة بصورة حقيقية محلية: السلم يسارًا والنص العربي يمينًا فوق تدرج للقراءة. العنوان والوصف المعتمدان وزر استكشاف المنتجات وحده. انعكاس خفيف يتوقف ويختفي مع تفضيل تقليل الحركة.
- ثلاث بطاقات خدمات وأقسام تفصيلية: التجهيز، التركيب، الصيانة والدعم بالأوصاف المعتمدة وترجمتها. أُزيلت خدمة التوصيل دون إضافة التزامات تجارية.
- أيقونات SVG للهاتف وواتساب والخدمات. ترتيب أدوات الهيدر: واتساب، الهاتف، اللغة، المظهر؛ اختصارات التواصل داخل القائمة على الشاشات الضيقة.
- إبراز عنوان المنتجات وتعديل الرابط إلى «عرض كل المنتجات». إزاحة الصور قليلًا للأعلى مع احتوائها كاملة دون قص أو تغيير ملفاتها. إصلاح قياس شبكة الصور الذي كان يسمح بخروجها عن المساحة. الأسماء والأوصاف أسفل الصور.
- شريط التواصل بالنص المعتمد وزر واتساب بالجانب المقابل ويُرتب رأسيًا للموبايل. أُزيلت الفقاعة العائمة والدعوات المكررة من المحتوى. بقيت أدوات الهيدر والفوتر؛ رابط تفاصيل المنتج يحتفظ برسالته الخاصة بالمنتج.
- نص وصورة «من نحن» محدثان وحذف زر التواصل المكرر. التواصل: هاتف، واتساب، فيسبوك بعمود، والعنوان بالعمود المقابل.
- فوتر بثلاث مجموعات وشعار صغير وسطر الحقوق المعتمد. الحفاظ على Zain والألوان والشعار الشفاف المعتمد والوضعين.
- عناوين وأوصاف مستقلة وcanonical وhreflang وOpen Graph/Twitter بروابط مطلقة. صورة مشاركة 1200×630 تجمع الشعار الأصلي وصورة حمام السباحة والنص العربي.
- توحيد المصطلحات العربية المعروضة إلى «حمام السباحة/حمامات السباحة». بقي `catalog.json` وحقائق المنتجات وصورها دون تعديل؛ أُعيد توليد `catalog-data.js` لتوحيد المصطلحات المعروضة فقط.

## الصور

الصورة الجديدة قص من أصل حقيقي مرخص موجود بالمشروع، يظهر السلم والمياه بوضوح. لا يوجد أصل مطلوب مفقود. المصدر والترخيص في [IMAGE_SOURCES.md](../assets/IMAGE_SOURCES.md).

- [صورة الهيرو](../assets/pool-wide.jpg) ونسخة متجاوبة 1100px.
- [صورة المشاركة](../assets/og-axis-blue.png)، ومصدر تركيبها `qa/og-card.html`.
- لم تتغير أصول الشعار بهذه الجولة؛ استُخدمت النسخ الشفافة المعتمدة للايت والدارك دون خلفية بيضاء.

## نتائج التحقق

نجح `node build-pages.cjs` ثم `node verify-site.cjs`: **12 صفحة، 358 مرجعًا محليًا، 435 منتجًا فريدًا، 12 فئة** مع الروابط والبيانات الوصفية. نجحت فحوص صياغة JavaScript للمولد والسكربت وفحص المتصفح.

نجح `node qa/verify-ui.cjs`: **168 عرضًا فعليًا في Chrome**. كل عرض من 360 و390 و412 و768 و1024 و1440px شمل 28 حالة تجمع اللغتين والوضعين والصفحات الرئيسية والمنتجات والخدمات ومن نحن والتواصل والتفاصيل والكتالوج.

شملت الفحوص عدم التمرير الأفقي أو تصادم الهيدر، فتح القائمة والإغلاق بـEscape واستعادة الفوكس والتنقل، حفظ المظهر وإعادة التحميل وتطبيقه قبل أول إطار محتوى، حفظ سياق الصفحة والفلاتر عند تغيير اللغة، البحث بالكود والنتيجة الفارغة والتصنيف والترقيم والتفاصيل ورسالة واتساب الخاصة بالمنتج، الفوكس ولون واتساب، استمرارية الخطوط وتباين الأنماط المختبرة. لم تُرصد أخطاء JavaScript أو طلبات شبكة فاشلة بالمصفوفة.

نجحت مراجعة مركزة إضافية للخط السفلي والهوفر دون مربع، ترتيب أدوات الهيدر الفعلي، تقليل الحركة، غياب الزر العائم، عدد دعوات واتساب داخل المحتوى، احتواء صور المنتجات وترتيب التواصل. النتائج: [الفحص الشامل](results/verification.json) و[الفحص المركز](results/content-update/focused-checks.json).

## حدود التحقق

الاختبار في Chrome بأبعاد مختلفة ولم يتم على هاتف فعلي أو Safari. اختبار التباين للأنماط المختبرة لا يمثل تدقيق وصول شاملًا. لم تُجرَ مكالمات أو تُرسل رسائل. لم تتغير النسخة المنشورة.

تفاصيل المنتجات صفحة ثابتة مشتركة تعتمد على معرّف في الرابط؛ يحدث JavaScript البيانات الوصفية الخاصة بالمنتج داخل المتصفح. برامج المشاركة التي لا تشغله سترى بيانات صفحة التفاصيل العامة وصورة المشاركة المشتركة. تخصيص بيانات كل منتج لها يتطلب صفحات مستقلة أو توليدًا من الخادم، خارج نطاق الجولة.
