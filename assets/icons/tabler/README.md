# Contact icons

Four local SVGs from [Tabler Icons](https://github.com/tabler/tabler-icons), Outline family, retrieved 2026-10-25:

- `phone.svg`
- `brand-whatsapp.svg`
- `brand-facebook.svg`
- `map-pin.svg`

Source: `https://raw.githubusercontent.com/tabler/tabler-icons/main/icons/outline/`

Copyright Paweł Kuna. MIT license retained in `LICENSE`.

The page generator embeds their original drawing paths only for header/footer contact marks, using the same 2-unit rounded stroke. Header phone/WhatsApp have separate optical sizes; footer icon slots and layout stay unchanged. No browser dependency or remote icon request is required.

## Service icons — 2026-10-26
