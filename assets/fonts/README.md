# Local Zain WOFF2

Family: Zain, normal style, weights 400/700/800. Arabic and Latin subsets are stored locally as six WOFF2 files. Source: Google Fonts official stylesheet, retrieved 2026-10-26:
https://fonts.googleapis.com/css2?family=Zain:wght@400;700;800&display=block

Original font license retained in OFL.txt. The original unused TTF weights were replaced by these compressed assets; no font library or dependency was installed. Runtime pages make no Google Fonts requests. The combined files total 152,440 bytes; each document preloads the four 400/700 subsets (101,532 bytes), while weight 800 is loaded where used.
